### Репозиторий вебинара 12 мая

Основные команды:
1. git status - посмотреть статус файлов в репозитории.
2. git add - добавляем файл/изменение в нем к отправке.
3. git commit -m 'нормальное описание изменений' - добавка описания изменения.
4. git push origin ...название ветки... - отправка изменений на сервер.
